# Mon Écosystème Numérique de Thèse

Ce dépôt rassemble l'ensemble des livrables et ressources réalisés dans le cadre du mini-projet **« Mon écosystème numérique de thèse »** (Module : Transformation numérique et recherche).

## Structure du dépôt

* `/biblio` : Export de la bibliothèque Zotero au format `.bib` (références organisées et rétractations vérifiées).
* `/dmp` : Plan de gestion des données (modèle DMP OPIDoR).
* `/ia` : Bilan de l'activité 2 et charte personnelle d'utilisation de l'intelligence artificielle.
* `/docs` : Document de synthèse final (PDF).
